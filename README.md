# r3f-test

3D avatar prototype built with Next.js + React Three Fiber. Features an idle animation with organic semi-random rotation, a pendulum-based stabilization that keeps the model upright, and a click impulse that sends it spinning.

## Stack

- [Next.js](https://nextjs.org)
- [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber)
- [@react-three/drei](https://drei.pmnd.rs)

## Run locally

```bash
npm install
npm run dev
```
